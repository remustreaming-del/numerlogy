# Toono design

Purpose: a calm, mobile-friendly name → birth date → QPay → downloadable reading flow.

Palette: chalk #FAF9FD, midnight ink #292641, muted lavender #72608F, pale lilac #EEE9F5, dividers #E7E3EE. Cormorant Garamond is the editorial display face; Noto Sans supports English and Mongolian body text and embedded PDF glyphs. Both fonts are self-hosted with their licenses.

The desktop page pairs a left-aligned introduction with a numerology orbit, followed by a three-step process and an immediately visible form. Mobile stacks these elements. The orbit is the single expressive visual; controls and report pages remain quiet. Avoided generic astrology photography because the client's task is entering details and receiving a document. No automatic animation; reduced-motion preferences are respected.

Default working brand: Toono. Price: ₮5,000, fixed on the server. Mongolian-only interface and reports; name personalizes the report, birth date supplies the numbers.
